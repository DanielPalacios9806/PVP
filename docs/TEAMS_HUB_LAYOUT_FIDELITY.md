# Teams Hub Layout Fidelity

## Objetivo

La pantalla `/dashboard/teams` funciona como centro de rosters, capitanes y actividad competitiva dentro de Darkside.cool.

## Estado actual

- Mantiene `ResourcePanel kind="teams"` como fuente principal de datos.
- Presenta equipos existentes, estado y acciones de gestión.
- Se integra con el shell privado, rail derecho colapsable y bottom nav mobile.

## Criterios visuales

- Título claro orientado a rosters y actividad competitiva.
- Cards legibles y consistentes con Darkside UI.
- Acciones de equipo visibles sin invadir el layout.
- Responsive mobile apilado, sin sidebar obligatoria.

## Pendiente futuro

- Filtros por juego, rol o estado de reclutamiento.
- Vista de tryouts.
- Invitaciones y solicitudes pendientes con estados visuales.
