# Beta Release Notes Draft

## Darkside.cool / Arena OS - Beta cerrada

### Resumen

Darkside.cool entra en beta cerrada como plataforma web de torneos esports enfocada en gestión de equipos, torneos, brackets, partidas, cuenta competitiva, tokens internos no monetarios y operación administrativa.

### Incluye

- Landing pública Darkside.
- Dashboard competitivo.
- Hub de torneos.
- Tournament Detail con bracket visual.
- Hub de equipos.
- Account + Riot profile UX.
- Admin/Ops Center.
- Moderation War Room.
- Token Ledger interno no monetario.
- Health checks de Web/API/DB.
- Smoke remoto.
- Visual QA con Playwright.
- Riot Developer Application Package.

### Estado Riot

- `RIOT_API_MODE=development` para pruebas.
- `RIOT_API_KEY` solo en backend/API.
- RSO pendiente de aprobación Riot.
- Tournament API pendiente de aprobación Riot.
- Tokens internos no representan dinero real.
