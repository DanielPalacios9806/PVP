# Beta Tester Guide

## Propósito

Guía breve para testers internos de Darkside.cool durante beta cerrada.

## Antes de probar

Usar la URL enviada por el equipo. No compartir credenciales, capturas internas o enlaces administrativos fuera del grupo de prueba.

## Flujo usuario estándar

1. Abrir la landing.
2. Registrarse o iniciar sesión.
3. Entrar al dashboard.
4. Revisar torneos disponibles.
5. Abrir el detalle de un torneo.
6. Revisar bracket, reglas y panel contextual.
7. Revisar equipos.
8. Revisar cuenta y estado Riot.
9. Revisar tokens internos.
10. Reportar errores con captura, ruta y descripción.

## Flujo organizador/admin

1. Entrar con cuenta autorizada.
2. Revisar Admin/Ops Center.
3. Revisar auditoría, tokens, moderación y perfiles.
4. Confirmar que la navegación admin no aparece para usuarios normales.

## Qué reportar

- Pantallas cortadas en móvil.
- Botones sin acción.
- Errores 500/404 inesperados.
- Información sensible visible.
- Estados Riot confusos.
- Problemas de login o sesión.
- Datos inconsistentes en torneos/equipos.
